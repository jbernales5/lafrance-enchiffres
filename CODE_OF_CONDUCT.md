# Code de conduite

Ce projet documente des sujets sur lesquels les gens ne sont pas d'accord : dette, immigration, sécurité, climat, école. Le désaccord est donc attendu, et il est le bienvenu. Ce document dit comment il se tient ici.

## Ce qu'on attend

- **Discuter des chiffres, des définitions et des méthodes**, pas des personnes. « Cet indicateur masque X » est une contribution ; « tu es de tel camp » n'en est pas une.
- **Apporter une source** quand on conteste une valeur. On vérifie avant de contester : chaque graphe affiche la requête qui l'a produit et les sites d'origine.
- **Accepter qu'un choix soit discutable sans être malhonnête.** Choisir un indicateur, un champ ou une période est un choix et le contester est donc légitime.
- **Rester lisible.** Une issue courte et précise est traitée ; un fil de trente messages ne l'est pas.

## Ce qui n'a pas sa place

- Les attaques personnelles, le harcèlement, les insultes.
- Les propos discriminatoires, quel que soit le motif.
- Le procès d'intention sur les motivations d'un contributeur ou du mainteneur.
- La publication d'informations privées sur quiconque.
- L'usage du dépôt comme tribune : les issues servent à améliorer le site, pas à tenir un débat politique général.

## Portée

Ce code s'applique aux issues, aux pull requests, aux commentaires de commit et à tout espace où quelqu'un représente le projet.

## Signaler

Écrivez au mainteneur en ouvrant une issue, ou en privé via le profil GitHub indiqué dans `README.md` si le sujet ne peut pas être public.

## Réponse

Le mainteneur répond aux signalements et peut, selon la gravité : demander une reformulation, masquer un commentaire, fermer une issue, ou bloquer un compte. Les décisions de modération sont motivées publiquement quand elles portent sur un contenu public.

Ce code s'inspire du [Contributor Covenant](https://www.contributor-covenant.org/), adapté à un projet dont le sujet est politique mais dont la méthode ne l'est pas.
